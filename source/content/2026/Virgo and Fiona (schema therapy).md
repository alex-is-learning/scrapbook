Copy-paste from README as of 2026-04-02:

Two Claude Code skills for personal schema therapy work, built from _Breaking Negative Thinking Patterns_ (Jacob, van Genderen & Seebauer, 2014). Forked from [Dave](https://github.com/alex-is-learning/dave).

- **Virgo** — maps Alex's internal landscape using the Schema Mode approach. Guides through Part I worksheets: mode identification (triggers, feelings, thoughts, memories, body, behaviours, needs). Output is structured markdown files in a private Obsidian vault.
- **Fiona** — exercise guide who works from Virgo's map. Guides through Part II exercises: imagery rescripting, chair work, inner helper, affective bridge, letter to inner child, and more.

Will be using my private vault for this. I'm excited!!!
